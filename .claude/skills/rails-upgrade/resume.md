# resume（次の作業を判断し、作業の始めの準備をする）

## 入口の条件

- `/rails-upgrade` が引数なしか `resume` で呼ばれた

## 手順

1. 設定の「計画」のロードマップとチェックリスト、設定の「記録」の最後の節を読み、次の作業（どの Step の、どの作業か）を決める
   - 前の Step の PR がまだ取り込まれていなければ、その旨を示して止まる
   - Step の途中なら、チェックリストで終わっていない最初の作業
   - 次の Step の始めなら research
2. 作業ブランチを確かめる（設定の「ブランチと PR」）。Step の始めで、まだなければ、ブランチを切ることを提案する
3. Step の始めなら、作業の始めの準備をする
   - 前の Step の PR へのリンクが記録にまだなければ、記録を直して最初のコミットにする（設定の「記録」）
   - 手動確認用の環境（設定の「手動確認用の環境」）のハッシュと件数を控え、記録にある基準と比べる
4. 次の作業と、その作業のファイルを示す

## 関門

- なし（ブランチを切る・最初のコミットは、設定の「ブランチと PR」の決まりのとおりに行う）

## 出口の条件と記録

- 次の作業と、そこまでの状態（ブランチ、手動確認用の環境の控え）を示した
