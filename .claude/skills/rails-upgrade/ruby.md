# ruby（Ruby を上げる）

Ruby だけを上げる。周辺 gem は、別の作業（gems）か別の Step にする。

## 入口の条件

- 作業計画が承認され、上げる版が決まっている
- Ruby のダウンロード（またはビルド）の承認を得ている

## 手順

1. 前の Ruby のうちに、前の書き出しを取る（[before-after.md](before-after.md)）
2. 新しい Ruby を入れる。入れ方と、入れた後の確かめ方は設定の「作業ごとの参照」の ruby の行
3. 新しい Ruby の default gem の版を調べ、lock に入れた default gem と、一時固定した gem を合わせ直す方針を決める（設定の「計画」の Ruby を上げるときの手順）。lock の合わせ直しは、コピーで試してからアプリに持ち込む
4. gem を入れ直す。意図しないダウンロードが起きない方法で行い、入れた後にダウンロードがなかったこと、コピーした `.gem` の照合（設定の「道具」）を確かめる
5. 後の書き出しを取って比べる（[before-after.md](before-after.md)）
6. アプリごとにコミットする（[commit.md](commit.md)）。Ruby の版を持つファイルは、設定の「作業ごとの参照」の ruby の行
7. 静的解析の対象の Ruby の版は、別のコミットで上げる

## 関門

- 判断の関門: Ruby のダウンロード、default gem の合わせ直しの版、手動確認の時期
- 意図しないダウンロードが起きそうなとき・起きたときは止まる

## 出口の条件と記録

- Ruby の版、落としたもの、合わせ直した default gem、前後の比較の結果を、記録の下書きに控えた
