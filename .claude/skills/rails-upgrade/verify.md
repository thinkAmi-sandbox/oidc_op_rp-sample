# verify（完了条件の確認）

## 入口の条件

- この Step の変更をすべてコミットした

## 手順

1. 設定の「計画」の完了条件を 1 つずつ確かめる。まとめて流せる検査は設定の「検査のコマンド」
2. 検査で確かめられないもの（`rails c` の起動、lock の default gem と一時固定の版、手動確認用の環境）は、設定の「作業ごとの参照」の verify の行の方法で確かめる
3. 手動確認がまだなら、作業計画で決めたとおりに行う（[manual-check.md](manual-check.md)）
4. 完了条件のうち、確かめられなかったものは、その理由とともに示して止まる

## 関門

- 判断の関門: 手動確認の時期

## 出口の条件と記録

- 完了条件ごとの結果（件数の要約）を、記録の下書きに控えた
