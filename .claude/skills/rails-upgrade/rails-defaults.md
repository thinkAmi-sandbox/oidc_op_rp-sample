# rails-defaults（`new_framework_defaults_*.rb` をグループごとに有効にする）

## 入口の条件

- rails-app-update が終わり、`new_framework_defaults_*.rb` がある

## 手順

1. 設定をグループに分ける（挙動が変わらないもの、テストだけ、内部の処理だけ、応答が変わるもの、既存のデータに影響するもの、のように、確かめ方が同じものをまとめる）。各グループの見込みと確かめ方を、表で示す
2. グループの順を決める（判断の関門）
3. グループごとに、次を繰り返す
   1. 前の書き出しを取る（[before-after.md](before-after.md)）
   2. グループの設定を有効にする
   3. 後の書き出しを取って比べる。設定が効いていない（値が変わらない）ときは、起動の途中の読み込みを疑い、止まって調べる
   4. 追随の解説（[explain.md](explain.md)）。返事の後に、アプリごとにコミットする
4. 手動確認が要るグループ（既存のデータや Cookie に影響するもの）は、作業計画で決めた時期に行う（[manual-check.md](manual-check.md)）

## 関門

- 判断の関門: グループの順、手動確認の時期
- 理解の関門: 各グループの既定値への追随

## 出口の条件と記録

- すべてのグループが有効になり、グループごとの解説と比べた結果を、記録の Step の節に足した。設定の「計画」のチェックリストの、この作業の項目を済みにし、docs のコミットにする（セッションが変わっても、resume が続きから始められるようにするため）
