# 前後の比較

gems・ruby・rails-defaults・rails-load-defaults から呼ぶ。変更の前に書き出し、変更の後に書き出して比べる。差分が、追随の解説（[explain.md](explain.md)）と業務的な挙動の変化での停止（[templates.md](templates.md)）の根拠になる。

## 手順

1. 変更の前に、設定の「前後の比較」にある書き出しをすべて取る。変更の後では取り直せないので、先に取る
2. 変更する
3. 同じ書き出しを取り、比べる
4. 違いを振り分ける
   - 違いがない: そのまま進む
   - 業務的な挙動の変化（設定の「業務的な挙動の定義」）: 止まる（[templates.md](templates.md) の「業務的な挙動の変化での停止」）
   - 既定値・雛形への追随: [explain.md](explain.md)
   - 理由が分からない: 止まって質問する
5. 比べた範囲と結果を、記録の Step の節に控える（何と何を比べ、何が違ったか。比べていないものは「変わらない」と書かない）

## 止まる条件

- 書き出しが毎回同じにならない（比べる前に、何が毎回変わるのかを確かめる）
- 比べる書き出しの一部が取れない
